# Asset Licenses

This supplementary package contains code and derived research artifacts for
anonymous NeurIPS review.

External assets:

- CaSiNo dataset: Chawla et al. (2021). Used under the dataset's published
  access terms.
- Deal-or-No-Deal dataset: Lewis et al. (2017). Used under the original dataset
  release terms.
- Llama-3.1-8B-Instruct and Llama-3.3-70B-Instruct: used under the applicable
  Meta Llama Community License and acceptable-use policy.

We do not redistribute full Llama base-model weights. If LoRA adapters are
released, the release will include the required Llama license copy, NOTICE
attribution, and "Built with Llama" documentation.

For the anonymous reviewer supplement, included dataset-derived files are only
the split/data artifacts needed to validate the paper-facing code paths and
tables. A public release should re-check upstream redistribution terms and, if
needed, replace full data files with split identifiers and acquisition
instructions.
